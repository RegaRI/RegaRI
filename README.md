### About

I'm a Computer Science student exploring the space where data, models, and real applications meet. My coursework and side projects span Machine Learning, Data Mining, Cryptography, and Image Processing, and I enjoy turning that theory into things people can actually use — chatbots, classifiers, and web or mobile apps.

- Currently exploring NLP and NLU, moving from classic SVM/TF-IDF pipelines toward fine-tuned IndoBERT models
- Building end-to-end projects: from data preprocessing and model training to deployment
- Comfortable across both mobile (Flutter) and web (PHP) development
- Interested in practical, locally-run AI — including chatbots powered by on-device LLMs
